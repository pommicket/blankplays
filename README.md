# BlankPlays

https://blankplays.pommicket.com

A free & ad-free online puzzle game: find every possible play with a single blank in a given
Scrabble®* position.

\* BlankPlays is not an official or approved Scrabble product and is not associated with Hasbro or Mattel in any way.

The main files of interest here are `pub/index.html`, `pub/index.css`, and `pub/blankplays.js`.
In the `extractor` directory you will find the script for extracting puzzles from Macondo game logs.
